# 只裁切模式

**只有一堆扫描件，文件名乱七八糟，没有接图表，也不知道经纬度 —— 能不能用？**

**能，而且这是最简单的用法。**

---

## 一、为什么可以

本工具包的处理分成**两个互相独立**的阶段：

```
01_crop.py     纠斜 → 找图廓 → 裁到内容 → 输出图片
                            ↑
                    完全不关心文件名、图号、经纬度

02_georef.py   文件名 → 图号 → 经纬度 → 写进 GeoTIFF
                            ↑
                  只在这一步才需要命名规范
```

**所以只跑 `01_crop.py` 就够了，后面两步直接跳过。**

实测：文件名是 `IMG_20240315_142233.jpg`、`微信图片_2024.jpg`、`老地图 副本.jpg`
这种完全不规范的，6 幅全部正常裁切，零失败。

---

## 二、怎么做

### 2.1 准备

1. 把扫描件全部丢进 `input/`
2. 复制配置模板：
   ```
   copy config.example.yaml config.yaml
   ```
3. 用记事本打开 `config.yaml`，决定输出尺寸（见下一节）

### 2.2 运行

**双击 `一键运行.bat` 不行** —— 它会连着跑 02、03，而 02 需要解析图号。

**方式一：自己填尺寸（推荐）**

双击 **`自定义尺寸裁切.bat`**，它会问你输出尺寸：

```
请输入输出尺寸
  直接回车 = 用配置文件里的尺寸
  常用参考：
    3000x2000     较小，适合屏幕浏览
    4500x3500     默认值（对应 15' x 10' 的图幅比例）
    6000x4500     较大，适合打印
    original      不缩放，保持扫描原分辨率

  尺寸(例如 4500x3500 或 3000x2000k):
```

**在尺寸末尾加 `k`**（如 `3000x2000k`）= 保持比例、居中补白，绝不会拉伸变形。

**方式二：命令行直接指定**

```bash
# 指定尺寸
python scripts/01_crop.py -s 3000x2000

# 保持比例（不会变形），居中补白
python scripts/01_crop.py -s 3000x2000 --keep-aspect

# 不缩放，保留原始像素
python scripts/01_crop.py -s original

# 指定尺寸 + 只重跑某一幅
python scripts/01_crop.py -s 3000x2000 某幅的文件名
```

尺寸写法很宽松，下面这些都认：

```
3000x2000    3000X2000    3000*2000    3000,2000
```

命令行给的尺寸**优先级高于 `config.yaml`**，且**不会修改配置文件** ——
适合快速试几个尺寸看效果。

看帮助：

```bash
python scripts/01_crop.py -h
```

**方式三：不用任何参数**

```bash
python scripts/01_crop.py
```

直接用 `config.yaml` 里 `crop.out_size` 的值。

### 2.3 结果

- 输出在 `work/01_crop/`，文件名是 **`<原名>_inner.png`**
- 尺寸统一（或保持原始，取决于配置）
- `crop_report.json` 里有每幅的角度、外框、比值

**到此结束。** 不需要图号，不需要接图表，不需要经纬度。

## 三、输出尺寸怎么选

这是只裁切模式下**唯一需要动脑子**的地方。

**别猜 —— 先让工具测一遍：**

```bash
python scripts/tools/probe_resolution.py
```

它会抽样跑一遍「纠斜 → 找图廓 → 找内容边界」，报出你的扫描件**裁到内容后
实际是多少像素**，然后给几档建议（含各档的代价）。详见 README 的
「不确定输出尺寸该填多少」一节。

测完再决定下面这张表怎么填：

```yaml
crop:
  out_size: [4500, 3500]
  keep_aspect: false
```

| 你想要 | 配置 | 结果 |
|---|---|---|
| **尺寸统一，不介意轻微变形** | `out_size: [4500, 3500]`<br>`keep_aspect: false` | 全部拉伸到 4500×3500 |
| **尺寸统一，且不能变形** | `out_size: [4500, 3500]`<br>`keep_aspect: true` | 按比例缩放，居中补白 |
| **不要缩放，保留原始清晰度** | `out_size: null` | 保持裁切后的原始像素 |

### ⚠ 默认值是给经纬度网格用的

`4500×3500` 这个比例（1.2857）不是随便定的 —— 它对应"15′ 经差 × 10′ 纬差"
在纬度 32° 附近的地面距离比，这样配准后像素的地面分辨率才接近各向同性。

**如果你的地图不是这个比例，用默认值就会被拉伸变形。**

举例：一幅正方形的地图（长宽比 1:1），强制拉到 1.2857:1，会被**横向拉宽 28%** ——
画面上看不出异常，但山会变胖、字会变宽。

**判断方法**：随便挑一幅，看图廓（边框）是不是接近 1.2857 : 1。

- 接近 → 用默认值，没问题
- 差得远 → 用 `keep_aspect: true` 或 `out_size: null`

**不确定就用 `keep_aspect: true`** —— 它最安全，最多补一圈很窄的白边。

## 四、还能调什么

只裁切时，这几个参数最有用：

| 参数 | 作用 | 什么时候调 |
|---|---|---|
| `density_threshold` | 内容密度阈值（默认 0.10） | 大片湖区/平原被切多了 → 调小到 0.06 |
| `safe_ratio` | 内容框小于此比例就整幅保留（默认 0.72） | 想更贴边裁 → 调小；想更保守 → 调大 |
| `force_safe` | 强制整幅保留的名单 | 某幅被切了内容 → 把文件名加进去 |
| `per_sheet` | 逐幅参数覆盖 | 某幅需要单独放宽阈值，又不想改全局 |
| `deskew` | 是否自动纠斜 | 扫描件很正可以关掉，省时间 |
| `exclude` | 排除的非地图文件 | 有封面、说明页混在里面 |

### 被切了内容怎么办（最需要会的一招）

**只重跑那一幅，不要全量重来**：

```bash
python scripts/01_crop.py 某幅的文件名
```

先用 `per_sheet` 给它单独放宽阈值：

```yaml
crop:
  per_sheet:
    "某幅的文件名":
      density_threshold: 0.06
```

跑完看 `crop_report.json` 里那一幅的 `ratios`，两个值都接近 1 就说明裁对了。

## 五、这个模式下的取舍

**能得到的：**

- 歪的图被摆正
- 黑边、纸白边被裁掉
- 尺寸统一（可选）
- 全程本地、免费、不需要任何 GIS 知识

**得不到的：**

- **没有地理坐标** —— 图片就是图片，不能与卫星影像叠加
- **不能拼接** —— 各幅之间没有位置关系，VRT 建不起来

如果你以后想要坐标，**裁切成果是可以复用的**：给文件按规定改名，
再跑 `02_georef.py` 即可，不需要重新裁切。

## 六、什么情况下你其实需要配准

| 你的目的 | 只裁切够吗 |
|---|---|
| 把老地图整理干净、方便翻阅 | ✅ 够 |
| 做 PPT / 出版插图 | ✅ 够 |
| 打印出来挂墙上 | ✅ 够 |
| 与现代地图对比，看某地八十年前什么样 | ❌ 需要配准 |
| 量算距离、面积 | ❌ 需要配准 |
| 把几百幅拼成一整张 | ❌ 需要配准 |

**判断标准很简单：要不要和别的地图叠在一起看？** 要，就得有坐标。

而配准的前提是**能确定每幅图该在哪** —— 要么文件名里有图号，
要么有接图表可以对照，要么图上印着经纬度。三者都没有的话，
只能靠人工找控制点做几何纠正，那属于另一个课题。

## 七、最小工作流

```
把图片丢进 input/
      ↓
config.yaml 里决定 out_size 与 keep_aspect
      ↓
python scripts/01_crop.py
      ↓
打开 work/01_crop/ 逐幅检查
      ↓
发现某幅被切了 → per_sheet 单独放宽 → 只重跑那一幅
      ↓
完成
```

**不需要**：规范命名、接图表、经纬度、QGIS、GDAL。
